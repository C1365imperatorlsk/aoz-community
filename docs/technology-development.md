# AOZ Community Hub — технологии

Рабочий модуль: академия, автозавод, альянс. 127 технологий, 1 498 уровней, 59 уникальных изображений. 8 языков. Три отсутствующие иконки походов обозначены заглушками.

## Запуск
Откройте `technology-preview.html` в браузере. Это автономный интерфейс без сетевых запросов, без реальной аналитики. Уровни и настройки сохраняются локально, если браузер допускает localStorage.

## Подключение
Скопируйте JS и CSS в `data/` основного проекта. Подключайте скрипты в порядке: data, locales, core, ui. Создайте контейнер `hubTech`, добавьте маршрут `tech` в `hubScreens`, разрешите плитку `tech`, вызовите `TechnologyUI.install(root, lang, metric => analyticsCount(metric))` после определения аналитики. Обновите языковую перерисовку через `hubLabels`. При публикации требуется зарегистрировать `section_tech` и `interact_tech` на клиенте, сервере и в базе, а также новый номер версии, если он изменён. Не добавляйте отдельную галочку аналитики.

## Проверка
`python test-technology.py` (Playwright и Chromium). Автоматическая проверка всех диапазонов уровней, ресурсных сумм, базового времени, требований, всех локализаций, карточек и калькуляторов. Время с бонусом — расчётная модель. Требования по уровням и интерпретация отдельных параметров пожертвований остаются предварительными; необходима сверка с игровым интерфейсом. Права на игру и сторонние материалы принадлежат соответствующим правообладателям.
