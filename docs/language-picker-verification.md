## Реализация

- Собственная модальная панель: тёмное стекло, голубой контур и мягкое свечение, локализованный заголовок с глобусом, компактные строки с полной родной подписью языка, выделение выбранного языка и голубая галочка физически справа, включая арабский.
- Русский, English, Español, Tiếng Việt, العربية, 繁體中文, Hrvatski, Italiano. Флагов нет. Заголовок, доступное имя кнопки открытия и кнопка закрытия переведены на восемь языков.
- Системный `<select id="lang">` заменён скрытым полем состояния. Пользователь работает только с HTML-кнопками, стандартное меню Android/iOS для языка не вызывается. Сохранились ID, `.value` и существующая цепочка события `change`: автоопределение Telegram/браузера, приоритет ручного выбора и оба прежних ключа хранения не переписаны.
- Локализация меняется без перезагрузки. Панель закрывается по выбору, кнопке закрытия, нажатию на затемнение или Escape. Фокус возвращается на кнопку; Tab остаётся в панели, стрелки/Home/End перемещают фокус по языкам.
- CSS учитывает узкий экран, безопасные отступы, низкую высоту и RTL. При нехватке высоты прокручивается список внутри панели. Учтено предпочтение уменьшенной анимации. Стили ограничены компонентом и местом для его кнопки в шапке.
