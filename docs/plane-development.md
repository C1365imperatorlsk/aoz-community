# Самолёт 2.0 — техническая приёмка 27.11.2026

- Повторная сверка обеих игровых сборок: шесть групп самолёта совпадают полностью. Проверено 8 468 отдельных значений, длин рядов и связей действующего калькулятора, расхождений нет. Числовые значения не изменены.
- 84 графические привязки, два оптимизированных атласа WebP без уменьшения исходных размеров. Все 51 карточка имеют игровое изображение. Три вида облика, три стадии каждого, восемь значков модификации, девять исходных вариантов самолёта, три фрагмента, три ресурса оборудования. Три иконки основных ресурсов (сплав, чертежи, компоненты) пока не идентифицированы, сохранены текстовые названия. Девятый вариант базового самолёта сохранён в атласе, но не выводится как подтверждённая стадия модификации. 
- Синтаксис 3 встроенных скриптов и модулей проверен; 1680 проверок имитации DOM на восьми языках, в том числе крайние уровни и привязки. Браузер/реальный Telegram не проверены, точные единицы отдельных активных эффектов остаются открытыми.
- Полная распакованная рабочая база и графика сохранены в закрытом хранилище владельца. В интерфейсе технические источники не показаны.

Это согласование формата общих атрибутов, не новая игровая проверка каждого значения; потребуется подтвердить на устройстве. Исходные числа и расчёт расходов не менялись.
- Добавлен быстрый переход к любой карточке развития и локализованная справка по воздушным испытаниям. Оригинальное описание подтверждает пятницу/субботу, учёт характеристик самолёта, базовый лимит 400 000 войск, предоставляемые войска, восстановление раненых, награды первого прохождения и зачистку ранее пройденных этапов. Назначение специальных записей и точный смысл всех полей не подтверждены; числовой прогноз победы не добавлен.
- Ресурсные текстуры 67240388/89/90 по точным идентификаторам не найдены; частичная визуальная проверка атласов не дала подтверждённого совпадения. Временные иконки сохранены. Не повторять поиск по текстовым ID как единственный метод; следующая задача — полный визуальный поиск и сверка в игре.

## Итоговая техническая приёмка 0.7.105 (27.11.2026)

- R2 повторно проверен: SHA-256 совпал, 664 записи ZIP без ошибок CRC. Все 6 групп конфигурации самолёта в оригинальной и китайской сборках идентичны. Независимая выборка из исходных таблиц и действующего калькулятора (9549 числовых значений: стоимости, мощь, эффекты, характеристики, опыт, уровни, включая альтернативные ряды) совпала по контрольному отпечатку FNV-1a 310325928; это контрольная сверка, не криптографическое доказательство равенства каждой записи. Существующий полный тест структуры: 6531 проверка, тест интерфейса: 2858 проверок.
- Новый автономный тест `node tests/plane-final-acceptance.test.js`: 30650 утверждений, 29400 диапазонов через фактическую функцию расчёта стоимости, 48 открытий вкладок, 288 действий, 650 значений сводного бюджета; проверки сохранения, смены языка, границ и предупреждений зависимостей. Тест использует имитацию DOM и не является проверкой реального устройства. Все 18 локальных скриптов компилируются вместе. Все 87 графических привязок внутри размеров изображений; 5 WebP-файлов прочитаны из GitHub, заголовки и размеры совпадают. Визуальный рендер в браузере не выполнен.
- 17 активных навыков и оба сопротивления сверены по игровым примерам, 23 атрибута классифицированы; 16 процентных пассивных атрибутов используют общую схему технологий, не каждый независимо проверен в игре. Два альтернативных ряда помех не интерпретированы, пользователю показаны подтверждённые варианты. Специальные строки испытаний не используются для неподтверждённого прогноза. Три скриншотные ресурсные иконки оставлены по решению владельца.
- Техническая приёмка пройдена в пределах тестируемого функционала. Публичная страница GitHub Pages недоступна для проверки из текущей среды; статусные проверки коммита пусты, доступные workflow runs не подтверждают развёртывание. Реальная визуальная проверка владельцем/игроками остаётся финальным шагом. Пользовательский код и номер версии не менялись.
