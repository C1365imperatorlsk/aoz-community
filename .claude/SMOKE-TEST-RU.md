# Приёмка Claude Code — только чтение

1. Открыть Claude Code (не обычный чат), отдельную облачную сессию с одним репозиторием и веткой claude-agents. Режим Plan; не подключать внешние MCP, ключи, Supabase или Drive. Проверить фактический checkout, доступные инструменты, загрузку CLAUDE.md и settings.json. Если ограничения не действуют или запуск агента недоступен — остановить тест и сообщить.
2. Убедиться, что зарегистрированы 21 проектных агентов, а не только найдены файлы. Проверить список инструментов каждого. Не имитировать запуск чтением markdown.
3. Главный агент читает AGENTS.md, актуальный контекст и ROADMAP.md, передаёт узкие задания. Вызвать по имени, последовательно:
   - context-manager: сводка текущего состояния, завершённое задание, ограничения, следующий разрешённый шаг; дать ссылки на файлы.
   - frontend-developer: найти файлы редактора сообщений, точки подключения и механизм локализации; только чтение, без предложения миграции.
   - code-reviewer: статическое ревью конкретных data/message-editor*.js; дать подтверждённые замечания с путями и строками, отделить риски от дефектов. Не менять файлы и не запускать тесты.
Дополнительная приёмка после успешного запуска первых трёх: вызвать tg-architect для карты интеграции SDK, tg-ux-engineer для проверки навигации и tg-sec-auditor для статического обзора границ авторизации. Проверить доступность навыка telegram-webapps, прочитать нужный справочник без выполнения примеров. Не проверять работающие сервисы.
4. Для каждого указать, был ли фактический вызов субагента и получен ли отдельный результат (если интерфейс показывает, указать идентификатор/событие). Указать доступные инструменты, ошибки, фактически проверенные файлы, неподтверждённые пункты. Не выдумывать токены или длительность.
5. Главный агент объединяет результаты и прекращает работу. Не создавать PR, не коммитить, не публиковать и не менять внешние сервисы. Отдельно указать, что не проверено. Полноценная разработка потребует отдельного разрешения и пересмотра read-only профиля.

Источник исходных шаблонов: https://github.com/VoltAgent/awesome-claude-code-subagents (MIT; .claude/LICENSE-VoltAgent). Проектные адаптации находятся в .claude/agents; первоначальные файлы сохранены в истории Git.
