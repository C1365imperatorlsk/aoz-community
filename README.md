# aoz-community
AOZ Community Hub — Game Calculators

## Official application

[Open AOZ Community Hub in Telegram](https://t.me/AOZV3CommunityBot?startapp)

Free, independent, community-oriented project. Sharing the official application link is welcome.

## Data sources

Game data (upgrade costs, levels, resources and other game statistics) is collected, structured and checked using in-game data, game-client data, player observations and in-game screenshots. We aim to keep the information up to date with the latest game version.

Public community references and third-party tools, including AOZStats, AoZ Codes, AoZ Tips and Age of Z Data, may be used for cross-checking numbers and identifying errors or discrepancies. These references are listed for verification purposes, not as sources for copying their code, interfaces or databases.

AOZ Community Hub is an independently developed community project. Matching numerical values across tools are to be expected when they describe the same game mechanics.

All rights to the game, its names and materials belong to their respective owners. Found an error in the numbers? Let us know and we will correct it.

## Источники данных

Игровые данные (стоимость улучшений, уровни, ресурсы и другие игровые характеристики) собираются, систематизируются и проверяются на основе данных самой игры, данных игрового клиента, наблюдений игроков и скриншотов из игры. Мы стремимся поддерживать актуальность информации в соответствии с последней версией игры.

Для контрольной сверки цифр и выявления ошибок или расхождений могут использоваться открытые справочники сообщества и сторонние инструменты, в том числе AOZStats, AoZ Codes, AoZ Tips и Age of Z Data. Эти ресурсы указаны для проверки данных, а не как источники для копирования их кода, интерфейсов или баз данных.

AOZ Community Hub — самостоятельно разрабатываемый проект для сообщества игроков. Совпадение числовых значений в разных инструментах закономерно, когда они описывают одни и те же игровые механики.

Все права на игру, её названия и материалы принадлежат их правообладателям. Нашли ошибку в цифрах? Напишите, исправим.
